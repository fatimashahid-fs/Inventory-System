# StyleStock – Inventory and Stock Management System

## Project Overview
StyleStock is a C++ based Inventory and Stock Management System developed as part of the Data Structures and Algorithms (DSA) Open-Ended Lab.

The system is designed to manage product records, monitor stock levels, process inventory transactions, and generate inventory reports through a simple menu-driven interface.

## Features

- **Product Management:** Add, update, and manage product records.
- **Search Products:** Search for specific products in the inventory.
- **Sort Inventory:** Organize products based on selected criteria.
- **Stock Management:** Monitor and manage product stock levels.
- **Inventory Reports:** Generate reports related to inventory.
- **Transaction History:** Keep track of inventory transactions.
- **Display All Products:** View all available product records.
- **Data Persistence:** Save records and load previously saved data.
